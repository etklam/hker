# Hong Kong directory

## Platform
web, with Telegram bot discovery.

## Users and purpose
Hong Kong visitors find useful local places, services, online shops, communities and information. Administrators curate the same catalog used by web and Telegram.

## Constraints
User-supplied rebuild brief is authoritative. Listings need not be physical places. External links are optional and repeatable. No public accounts, ratings, payments or subscriptions. PostgreSQL modular monolith; reuse existing authentication. First release requires taxonomy/listing CRUD, public discovery and guided bot search.

## Open decisions
Public brand remains HKER until a replacement name is supplied. No invented business listings.
